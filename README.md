# 🌙 Lunar Engine
Lunar is a lightweight general-purpose Lua engine with Roblox-like instances and stuff. It can be used for servers, games, web applications, and more.

Every instance is an object that can represent anything. For example, `Instance.new("Player")` could represent a player, while `Instance.new("Socket")` could represent a network socket.

Lunar also provides connections and signals.
